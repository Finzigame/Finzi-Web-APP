# Finzi Web

Version web (PWA) de Finzi, una app de educacion financiera gamificada.

## Desarrollo

```bash
npm install
npm run web
```

## Build

```bash
npx expo export --platform web
```

Genera los archivos estaticos en `dist/`. Tambien se incluye un `Dockerfile` para servirlos con nginx.
